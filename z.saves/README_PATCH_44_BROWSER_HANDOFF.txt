# VS.Helper 44 — Browser Handoff после Build Zip

После успешного `VS.Helper -> Build Zip` теперь цепочка такая:

1. Новый ZIP engine собирает архив по `VS.Helper.Zip.xml`.
2. ZIP кладётся в буфер обмена как file-drop.
3. Показывается окно с именем архива, количеством файлов и конфигом.
4. После нажатия `OK` запускается браузер на `https://chatgpt.com/`.
5. Пользователь прикрепляет ZIP из буфера/проводника и пишет: `продолжаем`.

Важно: handoff в браузер не должен ломать сам Build Zip. Если браузер не открылся, ZIP уже создан и лежит в `_zip`.
