# VS.Helper — команды

Краткое описание команд расширения **VS.Helper** и вложенных операций в **Tools**.

## Главное меню VS.Helper

### Build Zip
Собирает архив проекта по правилам из `VS.Helper.Zip.xml`.
Используется для быстрой передачи исходников без `bin`, `obj`, `.vs`, `.git`, старых `.zip`, `.vsix` и другого мусора.
Версию расширения не меняет.

### Create Zip Config
Создаёт или обновляет файл `VS.Helper.Zip.xml` в корне решения и открывает его для редактирования.
В этом файле задаются имя архива, стартовый проект, включаемые файлы и исключения.

### Self Upgrade
Поднимает `Identity Version` в `source.extension.vsixmanifest`, собирает свежий `.vsix` и запускает установку новой версии.
Работает без `uninstall`: если версия увеличена корректно, Visual Studio должна принять пакет как обновление.
Пишет лог self-upgrade, чтобы было видно, какая версия была и какая собрана.

### Run Swarm
Запускает набор внутренних AI/quality-агентов для проверки проекта.
Команда предназначена для поиска типичных проблем, слабых мест и кандидатов на исправление.

### Evolve Swarm
Запускает эволюционный режим swarm-агентов.
Используется для более глубокого прохода по проекту: анализ, предложения улучшений, оптимизация правил и памяти swarm-системы.

### Commit Stamp Sync Git
Формирует commit stamp и краткое описание staged-изменений.
Собирает commit message в формате `Stamp - описание`, затем выполняет Git sync-сценарий (`add`, `commit`, `pull --rebase`, `push`).

### Tools
Открывает окно дополнительных инструментов обслуживания проекта.
Все операции работают относительно открытого `.sln` или `.slnx`.

## Tools — вложенные операции

### Удалить пустые строки
Проходит по текстовым файлам выбранной маски и нормализует лишние пустые строки.
При включённом backup создаёт `.bak` перед изменением.

### Удалить строки #region #endregion
Удаляет строки с `#region` и `#endregion`, оставляя остальной код без изменений.
Полезно для очистки старых файлов от регионов.

### Найти и заменить
Ищет указанный текст и заменяет его на новый во всех файлах выбранной маски.
Поддерживает backup и dry run.

### Найти Class или значение в Class и добавить в папку проекта
Ищет файлы/классы по заданному значению и копирует найденное в указанную папку.
Используется для выборочного переноса нужных файлов.

### Удалить лишние ссылки на namespace
Чистит лишние или дублирующиеся блоки `using`/namespace-ссылок в исходниках.
Применяется для приведения файлов к более аккуратному виду.

### Собрать все namespace проекта
Сканирует проект и собирает найденные `namespace` в отдельный файл отчёта.
Нужен для анализа структуры проекта.

### Собрать нужные using Packages проекта
Сканирует `using`-директивы и сохраняет их в отчёт.
Помогает понять, какие пространства имён реально используются.

### Удалить *.bak-файлы
Удаляет резервные `.bak`-файлы в выбранной области.
Операция удобна после успешной проверки предыдущих массовых правок.

### Удалить файлы не входящие в проект
Сравнивает папку проекта с содержимым `.csproj` и находит файлы, которые не подключены к проекту.
Используется для очистки мусора и потерянных файлов.

### Синхронизировать файл проекта с образцом файла проекта
Сравнивает текущий `.csproj` с образцом и синхронизирует проектные элементы.
Нужно для выравнивания состава файлов между проектами.

### Конвертировать старый .csproj в SDK-style
Преобразует старый формат `.csproj` в SDK-style.
Сохраняет важные свойства проекта и делает backup перед изменениями.

### Перевести английский текст на русский в файлах проекта
Зарезервированная операция для будущего AI/API-перевода текста и комментариев.
В текущей версии полноценный перевод не подключён.

### Нормализовать сигнатуры методов
Приводит сигнатуры методов к более аккуратному виду по внутренним правилам нормализации.
Полезно после массовых переносов или генерации кода.

### Восстановление файлов CSharp из Bak
Восстанавливает `.cs`-файлы из созданных ранее `.bak`-копий.
Используется как быстрый откат после неудачной массовой операции.

### Восстановление using в указанном проекте
Восстанавливает или дополняет `using`-директивы в проекте на основе выбранного образца.
Нужно после чистки или синхронизации файлов.

### Добавить комментарий /*Путь к файлу*/ к файлам .cs в папке
Добавляет в `.cs`-файлы комментарий с путём к файлу.
Удобно для дальнейшего анализа, переноса или работы с AI.

### Создать VS.Helper.Zip.xml / обновить секцию Git
Создаёт или обновляет конфигурацию ZIP-сборки и связанную служебную секцию.
Близко по смыслу к основной команде **Create Zip Config**.

### Собрать ZIP по VS.Helper.Zip.xml
Напоминание/дубль для ZIP-сборки из Tools.
Основная рабочая команда для этого — **Build Zip** в главном меню VS.Helper.

### Commit + Pull(Rebase) + Push через TokenProtected
Напоминание/дубль для Git sync-сценария из Tools.
Основная рабочая команда для этого — **Commit Stamp Sync Git**.
